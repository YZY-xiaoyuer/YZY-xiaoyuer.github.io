# 关于我

你好，我是 YZY，一名专注于嵌入式系统与 AI Agent 工程的开发者。

## 技术方向

**嵌入式 & 驱动开发**
- MCU 裸机开发（ARM Cortex-M、STM32）、RTOS（FreeRTOS）
- Linux 设备驱动开发（字符设备、platform 驱动、DTS 配置）
- 硬件调试：JTAG/SWD、逻辑分析仪、示波器

**Linux 应用开发**
- 系统编程：文件 IO、进程/线程、IPC（管道/共享内存/Unix Socket）
- 网络编程：epoll、Reactor 模式、高并发服务器设计
- 性能调优：perf、eBPF、零拷贝

**C++ 工程实践**
- 现代 C++（11/14/17/20）：移动语义、模板元编程、并发库
- 工程工具链：CMake、AddressSanitizer、Valgrind、clang-tidy

**AI Agent 开发**
- LLM 应用工程：Prompt 工程、RAG 系统、工具调用（Function Calling）
- 多智能体框架：Claude API、LangChain、AutoGen
- 系统集成：将 AI 能力嵌入嵌入式/服务端工程场景
